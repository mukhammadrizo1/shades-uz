# shades-uz

> **SHADES Print Studio** — Zamonaviy poligrafiya, kiyimlarga bosma (DTF, ipak to‘r, kashta) va korporativ suvenirlar platformasi.

## 🚀 Texnologiyalar
- **Frontend**: Angular 22 (Standalone Components, Signals)
- **Rendering**: Angular SSR (Server-Side Rendering) & Prerendering
- **Design System**: Vanilla CSS, Dark Luxury Theme (Dark Navy & Pumpkin Orange), Bento Grid
- **Typography**: Unbounded & Inter (Google Fonts)
- **Tillar**: O‘zbekcha (Lotin), Ruscha, Inglizcha (Ko‘p tilli rejim)
- **Xarita**: Toshkent markazi demo interaktiv xaritasi va Yandex / Google Maps navigatsiyasi

## 🛠️ O‘rnatish va Ishga Tushirish

```bash
# Bog'liqliklarni o'rnatish
npm install

# Mahalliy ishlab chiqish (Development) serveri
npm start
# yoki
ng serve

# Ishlab chiqarish uchun yig'ish (Production Build)
npm run build

# SSR Serverni ishga tushirish
PORT=4200 node dist/concept-shades/server/server.mjs
```
